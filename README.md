# RoseCare AI

A modern Flutter mobile UI for a smart rose-care and farming robot. The app uses mock data and is structured to be easy to extend with Firebase, REST APIs, MQTT, or embedded sensor feeds later.

## Features

- Elegant splash, onboarding, and login flow
- Smart farming dashboard with live-feeling mock updates
- Notifications, robot status, soil moisture insights, history, and settings
- Clean architecture with `theme`, `models`, `services`, `screens`, and `widgets`
- Green and beige premium visual system

## Run

1. Install Flutter 3.22+ and Dart 3.4+.
2. From the project folder, run `flutter pub get`.
3. If platform folders are missing in your environment, run `flutter create .`.
4. Start the app with `flutter run`.

## Notes

- The current environment used to generate this project did not have the Flutter SDK available, so the code could not be executed locally here.
